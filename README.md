A real-time, AI-powered hand-tracking web app. Open your palm in front of your webcam and a glowing Rasengan orb appears above your hand — just like in the anime.

## ✨ Features
- 🖐️ Open-palm gesture spawns a rasengan
- 👐 Both hands tracked independently, each with its own orb and color
- 🦴 Glowing hand-skeleton overlay
- 🔒 Fully private — runs entirely in your browser, no data uploaded
- 🚀 Zero build step — just HTML, CSS, and JS

## 🛠️ Built With
- [MediaPipe Hands](https://google.github.io/mediapipe/solutions/hands.html)
- HTML5 / CSS3 / Vanilla JavaScript
- Canvas 2D API

## 🚀 Setup
```bash
git clone https://github.com/anyayadav98-stack/Naruto-Rasengan.git
cd Naruto-Rasengan
python -m http.server 8000
```
Open `http://localhost:8000` and allow camera access.
